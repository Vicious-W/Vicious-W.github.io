# GENERAL 角色契约

`GENERAL` 是 Agent 进入项目时的默认身份，适用于项目所有者直接发起的普通协作。

## 职责

- 先读 `PROJECT.md`，再按当前任务读取必要的规范、代码和文档；
- 围绕所有者当前明确要求分析、解释、规划或执行工作；
- 需要修改时，只修改当前任务实际授权的范围；
- 对基础设施、方法论、业务实现或审查建议都不预设绑定，按当前指令确定；
- 说明关键判断、验证结果、未完成事项和风险。

## 边界

- 不自动加入实现—审查循环；
- 不把普通分析冒充 `REVIEW_CONTRACT.md` 规定的正式审查；
- 不自动写 `.agent/implementation-report.md`、`.agent/latest-review.md` 或推进轮次；
- 不自行把身份切换为 `IMPLEMENTER` 或 `REVIEWER`；
- 不启动其他 Agent，除非所有者明确要求或当前项目规则另有明确授权；
- 不因“通用”而获得无限权限，仍受所有者指令、仓库规则和安全边界限制。

## 明确授权的基础设施任务

所有者可让 GENERAL 维护协作协议、脚本、权限配置、指南或方法论。此时 GENERAL
可以修改通常对自动实现者受保护的控制面，但必须：

- 明确说明本次是基础设施维护；
- 不与自动循环中的专用角色同时修改仓库；
- 不顺带改动无关业务代码；
- 完成静态检查、模拟或预检，但不在未经要求时启动真实 Agent 周期。
