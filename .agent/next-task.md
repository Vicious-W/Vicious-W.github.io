## Objective

不得在本轮扩建实验室、园区或外部世界。

## Locked owner decisions

- 右键按下时，以**画面正中心**对应的场景焦点作为旋转中心；
- 画面中心射线命中模型时，命中点成为本次右键拖动期间的固定焦点；
- 中心射线没有命中时，使用沿当前视线、基于既有焦距得到的稳定虚拟焦点；
- 右键拖动期间焦点不得漂移、跳换或跟随鼠标位置；
- 旋转必须明显慢于当前实现，目标灵敏度为约 `0.0018 rad/像素`，不得出现轻微拖动
  就转过大角度的情况；
- 右键按住时允许显示一个短暂、微弱、无文字的蓝色中心标记，使旋转中心可知；
- 滚轮沿当前观察方向连续靠近或远离，不改变相机 FOV；
- 滚轮输入必须按 `deltaMode` 归一化、限制单事件幅度并平滑收敛；从默认机位出发，
  一次普通滚轮事件不得直接到达最近或最远限制；
- 上、下、左、右方向键平移画面中心，相机和焦点一起移动；方向以当前画面的
  `up/right` 为准，而不是固定世界 X/Z；
- 方向键连续按住时按时间积分，松开、窗口失焦或标签页隐藏后立即停止，不得残留漂移；
- `Home` 与 `F` 继续恢复规范初始取景；
- 抓取玻璃期间相机输入暂停，`W/S` 继续控制玻璃上下，`A/D` 继续只控制玻璃水平
  偏航；未抓取时 `W/S/A/D/Q/E` 不再作为基础相机移动方案；
- 相机仍可通过中心旋转、方向键平移和滚轮推进进入水下、堆芯附近、地板以下与
  地下设备背面；
- 相机不参与刚体碰撞，不推动玻璃、设备或水体，也不复位或改写反应堆会话。

## Required work

1. 重构 `freeCamera.js` 的相机状态，使显示焦点、目标焦点、实际机位和距离在平滑运动
   过程中保持一致，避免不可见 pivot 漂移。
2. 在右键按下时从画面中心执行拾取并锁定本次轨道焦点；无命中时使用稳定回退焦点。
3. 降低并统一右键旋转灵敏度；俯仰继续有界，横向旋转保持连续。
4. 将滚轮改为归一化、有单事件上限、无过冲的平滑 dolly；抵达近距离后继续推进时
   也必须连续移动相机与焦点，不能用突变倍率跳转。
5. 增加方向键画面平移，确保任意 yaw/pitch 下的上下左右都与屏幕方向一致。
6. 重新定义输入所有权和失焦清理，避免相机、玻璃抓取与控制台持续输入互相驱动。
7. 更新相机逻辑测试与浏览器验证接口；不得通过只修改测试阈值掩盖实际手感问题。
8. 保持水面跨越光学、AUTO/MANUAL、玻璃抓取、音频解锁和会话复位不回退。

## Quantitative acceptance

- 从规范初始机位横向右键拖动 300 CSS 像素，yaw 变化目标为约 `0.54 rad`，允许
  `0.45–0.65 rad`，不得接近半圈；
- 右键拖动期间，锁定焦点投影与画面中心的偏差不超过 2 CSS 像素；
- 从初始距离执行一次归一化普通滚轮步进，目标距离变化不超过 8%，且产生可观察的
  中间状态；连续同向滚动时距离严格单调，不在两端之间跳变；
- 方向键在不同 yaw/pitch 下分别验证：左/右只沿画面水平移动，上/下只沿画面竖直
  移动，斜向组合归一化，不因帧率改变总移动量；
- 方向键释放、窗口 `blur`、页面隐藏和指针取消后，相机持续输入均为零；
- 抓取玻璃期间方向键、右键和滚轮不得同时移动相机；`W/S/A/D` 的既有玻璃行为保持；
- `Home/F` 在任意轨道、缩放、平移、水下和地下机位后都返回同一规范取景；
- 相机仍可到达水下、堆芯附近和地下层，跨越水面时光学连续，且不改变控制权或
  物理状态。
