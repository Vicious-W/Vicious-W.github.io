# 反应堆模型工程设计基线

DESIGN_STATUS: ACTIVE

本文件定义当前反应堆三维模型的工程事实、资料边界、结构分解、状态关系和验收条件。
它不是开发日志，不替代 `PROJECT_SPEC.md`，也不声称网页模型可以用于核工程计算。

## 1. 文档职责

- `PROJECT_SPEC.md` 决定产品目标和验收要求；
- 本文件决定反应堆目标如何映射为可核查的三维部件和状态；
- `src/scenes/reactor/reactorModel.js` 是当前实现；
- `.agent/implementation-report.md` 记录单轮实现证据；
- Git 保存已经被替代的方案和历史过程。

实施者不得用修改本文件的方式降低 `PROJECT_SPEC.md` 的要求。发现资料冲突、需要更换原型
或需要新的工程抽象时，应在实现报告中提出，交由项目所有者决定后再更新本基线。

## 2. 事实分类

文档中的陈述分为四类：

| 分类 | 含义 | 使用规则 |

## 3. 当前资料基线

### 3.1 General Atomics：TRIGA 产品与部件

来源：
[TRIGA Products and Technologies](https://www.ga.com/fission-energy-systems/triga-products-technologies/)

可支持的事实：

- 标准 Mark I/II TRIGA 燃料元件直径约 38 mm；
- 燃料为低浓铀—锆氢化物体系；
- 控制棒驱动是电机驱动的线性机构；
- 驱动机构包含电磁耦合、连接杆、管状外壳、位置反馈和失电释放；
- scram 时电磁铁失电，控制棒依靠释放后的下落重新插入堆芯；
- 仪控系统连续测量功率，并把棒位命令传给驱动机构。

该页面不能单独支持某一座反应堆的堆芯格位数量、控制棒数量或具体管路布局。

### 3.2 Pavia TRIGA Mark II：几何与热工水力

来源：
[Characterization of the TRIGA Mark II reactor full-power steady state](https://arxiv.org/pdf/1503.00873)

补充来源：
[IAEA / Pavia Control Rod Calibration](https://nucleus.iaea.org/sites/connect/RRIHpublic/CompendiumDB/Shared%20Documents/Italy/Protocols%20in%20PDF/1_Control_rod_calibration_in_a_TRIGA_reactor.pdf)

可支持的事实：

- 研究对象是池式、轻水冷却并部分由轻水慢化的 TRIGA Mark II；
- 堆芯为直径约 44.6 cm 的圆柱形区域；
- 上下铝栅格板间距约 64.8 cm、厚约 1.9 cm；
- 中央 A 位是辐照套管，B–F 五个同心环共有 90 个元件位置；
- 燃料元件总长约 72.06 cm、直径约 3.76 cm，燃料有效段长约 35.60 cm；
- 该 Pavia 构型有 SHIM、REG、TRANS 三根控制棒；
- SHIM、TRANS、REG 分别位于 C、D、E 环；
- SHIM 和 REG 使用齿条驱动，抽出速度约 0.5 cm/s；TRANS 承担快速停堆功能；
- 反应堆水箱使用去离子轻水，直径约 1.98 m、高约 6.4 m；
- 堆芯外有约 30 cm 厚径向石墨反射体，燃料元件端部包含轴向石墨反射段；
- Ra–Be 中子源使启动阶段的中子通量可检测；
- Pavia 过去曾获脉冲运行许可，脉冲峰值约 250 MW、持续数十毫秒；
- 燃料温度升高会通过锆氢化物的负温度反应性反馈降低反应性；
- 堆芯依靠自然循环冷却，并存在二次冷却回路；
- 论文中的热工水力与中子学模型是工程分析，不等于本项目的实时视觉模型。

### 3.3 Oregon State TRIGA Mark II：运行现象

来源：
[1.1 MW TRIGA Mark II Pulsing Research Reactor](https://engineering.oregonstate.edu/NSE/research-innovation/facilities/11-mw-triga-mark-ii-pulsing-research-reactor)

可支持的事实：

- OSTR 是水冷、低浓铀/锆氢化物燃料、圆形栅格阵列的 TRIGA 研究堆；
- 它具有可快速弹出的瞬发棒；
- 瞬发棒引入反应性后出现功率脉冲和蓝色切伦科夫闪光；
- 锆氢化物燃料的瞬发负温度系数会使脉冲自行衰减。

OSTR 页面适合支持运行现象，不能替代 Pavia 资料中的具体尺寸，也不能证明两座反应堆
拥有相同格位和控制棒构型。

### 3.4 U.S. Department of Energy：切伦科夫辐射

来源：
[Cherenkov Radiation, Explained](https://www.energy.gov/ne/articles/cherenkov-radiation-explained)

可支持的事实：

- 带电粒子在水等透明介质中的传播速度超过该介质中的光速时会产生切伦科夫辐射；
- 可见光通常呈蓝色或紫色；
- 辉光位于透明介质中的堆芯周围，不是水面本身发出的普通蓝光。

## 4. 已确定的原型决策

### D-001：轻水与重水

项目采用 TRIGA Mark II，池内介质采用轻水。产品规范和后续实现不得使用“重水”
名称，也不得建立“TRIGA 外形 + 重水名称”的混合模型。

### D-002：具体 TRIGA 构型

项目以 **Pavia TRIGA Mark II** 作为几何和控制棒构型基线：

- 中央 A 位为辐照套管，B–F 五个环提供 90 个元件位置；
- SHIM、REG、TRANS 三根控制棒；
- 论文给出的堆芯和燃料元件尺寸是统一比例尺的主要依据；
- General Atomics 资料用于补充不冲突的通用燃料和控制棒驱动机构；
- Oregon State 资料只能补充不冲突的运行现象，不能改变 Pavia 的格位、棒数和尺寸；
- DOE 资料用于切伦科夫光学事实。

当前代码仍存在待实现纠正的旧近似：

- 当前代码：按 `1 + 6 + 12 + 18 + 24 + 30 = 91` 个位置生成六层阵列，
  把中央 A 位也作为燃料位置，并在 D 环设置四根控制棒；
- 除四个控制棒位置外，其余位置全部生成燃料，没有 Pavia 的石墨元件、中子源、
  辐照通道和真实装载图；

这些差距必须按 Pavia 构型重建，不能再通过选择其他设施解释。

## 5. 当前场景坐标

Three.js 使用右手坐标系：

- `y = 0`：池口甲板和名义水面高度；
- `y < 0`：水池与堆芯内部；
- `y > 0`：驱动桥、套管和玻璃层方向；
- `x/z`：俯视平面；
- 世界单位经过归一化，`1` 约等于一个玻璃立方体边长，不等于米或厘米。

当前主要常量：

| 常量 | 当前值 | 当前含义 | 状态 |
| --- | ---: | --- | --- |
| `POOL_RADIUS` | 3.4 | 水池内衬半径 | 当前近似 |
| `POOL_DEPTH` | 6.5 | 水面到池底 | 当前近似 |
| `CORE_RING_F` | 1.15 | 最外生成环半径 | 当前近似 |
| `ROD_R` | 0.085 | 燃料元件半径 | 由视觉比例近似 |
| `CORE_TOP` | -0.42 | 燃料段顶部 | 当前近似 |
| `CORE_H` | 1.72 | 代码中的燃料段高度 | 当前近似 |
| `REFL_IN/OUT` | 1.32/1.68 | 连续反射体环内外半径 | 当前近似 |
| `CTRL_TRAVEL` | 1.45 | 控制棒视觉行程 | 当前近似 |

后续必须以 Pavia 资料建立统一比例尺。燃料直径、燃料长度、堆芯直径、格距、
控制棒行程和水深应来自同一构型或有明确换算，不再逐项凭视觉调整。

## 6. 部件分解

### 6.1 池体、内衬与甲板

当前实现：

- 圆柱内衬；
- 池底圆盘；
- 带中央开口的环形甲板；
- 池口金属井唇。

独立性要求：

- 内衬、池底、甲板和井唇分别建模；
- 池体必须产生真实遮挡、内壁反射和深度关系；
- 不得用一张俯视圆形图片代替水池。

当前缺口：

- 池体尺寸没有和具体设施资料绑定；
- 池壁厚度、维护结构、平台开口和管道穿透尚未建模。

验收：

- 改变相机位置时能看到池壁厚度和池底深度；
- 水体关闭后仍能辨认独立池体结构；
- 不存在承担完整池体外观的背景贴图。

### 6.2 水介质

当前实现：

- 没有独立水体体积或物理水面；
- 大范围蓝色 halo 和核心点光只能表达光照，不能算作水模型。

目标结构：

- 独立水体边界；
- 可见水面或水体体积；
- 深度吸收、折射、反射和水下散射；
- 水体状态由明确的水位、扰动或热状态控制；
- 切伦科夫光位于水体内部并受水介质影响。

验收：

- 能单独显示或隐藏水体对象；
- 从不同视角可确认水面、池壁和堆芯的空间顺序；
- 移除辉光后水仍然可辨认；
- 不把颜色为蓝的透明平面直接称为轻水物理系统。

### 6.3 堆芯格架与栅格板

当前实现：

- 上、下栅格板分别是实心圆柱薄板；
- 燃料元件直接穿过板面，没有逐孔或支承结构。

目标结构：

- 上、下支承板为独立对象；
- 格位和燃料/控制元件位置使用同一坐标表；
- 可见范围内表达孔、套管或等价支承关系；
- 中央 A 位、B–F 的 90 个位置和非燃料装载必须来自 Pavia 构型。

验收：

- 任一燃料或控制元件都能追溯到一个格位；
- 不出现燃料棒穿透无孔实心板的视觉矛盾；
- 格架关闭后燃料元件仍独立存在。

### 6.4 燃料元件

资料事实：

- 标准 TRIGA Mark I/II 燃料元件直径约 38 mm；
- Pavia 元件总长约 72.06 cm，燃料有效段长约 35.60 cm。

当前实现：

- 使用圆柱几何；
- 使用三个 `InstancedMesh` 批次表达不同亮度；
- 顶部有独立金属端接头；
- 元件亮度由 `power` 代理状态驱动。

当前缺口：

- 圆柱没有分解包壳、燃料有效段、石墨端区和端部结构；
- 亮度档位由稳定伪随机数分配，不来自功率分布；
- 当前把除控制棒外的全部位置都当成燃料，与 Pavia 装载构型不一致。

验收：

- 单个元件至少分解为包壳、有效燃料段和端部结构；
- 位置、长度和直径使用统一比例；
- 若显示径向/轴向功率差异，必须由明确函数或数据驱动，不使用无意义随机闪烁。

### 6.5 反射体

当前实现：

- 用内外圆柱壁和顶环组成连续石墨环。

当前缺口：

- 连续环是视觉近似，不代表已验证的具体 TRIGA 反射体构造；
- 没有表达反射体块、穿孔、实验孔道或与格架的连接。

验收：

- 依据 Pavia 资料确定连续环还是离散石墨元件；
- 反射体与燃料区、实验孔和池水有清晰空间边界；
- 材料和结构不能只靠深色圆环暗示。

### 6.6 控制棒与驱动机构

资料事实：

- 控制棒是线性运动部件；
- General Atomics 驱动包含电机、位置反馈、电磁耦合、连接杆和管状外壳；
- scram 时电磁铁释放，控制棒重新插入堆芯；
- Pavia 构型有 SHIM、TRANS、REG 三根控制棒，分别位于 C、D、E 环；
- SHIM 和 REG 承担粗调与细调，TRANS 承担快速停堆功能。

当前实现：

- 四组吸收体和连接杆；
- 四个固定套管；
- 十字形跨池驱动桥；
- 全部控制棒共享同一个插入量。

当前缺口：

- 数量和位置与 Pavia 三棒构型不一致；
- 没有独立棒型、独立棒位、驱动电机、电磁耦合和 scram 状态；
- 十字桥是构图近似，没有资料证明；
- 当前缓慢正弦运动不是操作逻辑。

验收：

- 每根棒拥有独立标识、类型、位置、行程和状态；
- 正常驱动与 scram 是不同状态转换；
- 插入量变化由操作状态触发，不是无条件装饰循环；
- 位置反馈和至少一个可见仪器响应保持一致。

### 6.7 冷却、辐照与仪器结构

当前实现：

- 两根通用竖直导管；
- 一组沿池壁的竖管与横管；
- 十二段功率指示条。

当前缺口：

- 导管用途、入口、出口和几何没有资料映射；
- 冷却回路没有流向、泵/换热边界或自然循环表达；
- 功率条位于桥上是网页可视化设计，不是已验证的真实仪表位置。

验收：

- 每条可见管路必须标明用途和资料依据；
- 管路应有完整或明确截断的连接关系，不能悬空；
- 仪器显示可以为网页抽象，但必须在文档中标为抽象，并由同一状态源驱动。

### 6.8 切伦科夫辉光

当前实现：

- 加性发光盘；
- 更大的池水蓝色 halo；
- 核心点光源；
- 燃料材质自发光。

当前近似：

- 没有带电粒子输运、光子追踪或体积散射；
- 发光盘和点光源是实时视觉近似；
- 当前轻微多频闪烁是视觉噪声，不是中子学计算。

验收：

- 辉光位于水体内部和堆芯附近；
- 强度由统一功率状态驱动；
- 水面本身不能作为无因蓝色光源；
- 若使用 shader，只能附着于真实几何或水体光学层，不能绘制虚假堆芯。

## 7. 状态与运行链

SOURCE 的页面加载、启动、稳态、可选历史脉冲和重置时间线定义在
`SOURCE_SCENE.md`。本节只定义反应堆内部状态关系。

### 7.1 当前实现

当前状态：

```text
rodInsertion
    ↓
power（视觉功率代理）
    ├── fuel emissive
    ├── core glow
    ├── pool halo
    ├── core point light
    └── power indicator
```

当前代码使用正弦目标驱动控制棒，再用一阶迟滞使 `power` 跟随。它可以证明多个部件
共享同一状态，但不是点堆动力学、热工水力或真实控制系统。

### 7.2 最低可信状态模型

按 Pavia TRIGA Mark II 基线，至少需要：

| 状态 | 含义 | 影响对象 |
| --- | --- | --- |
| `operatingMode` | shutdown、startup、steady、scram；是否增加 pulse 取决于原型 | 全系统 |
| `rodPosition[]` | 每根控制棒独立插入位置 | 控制棒、驱动、位置反馈 |
| `reactivityProxy` | 由棒位和反馈项计算的定性反应性 | 功率变化方向 |
| `powerProxy` | 归一化视觉功率，不标称真实 MW | 燃料、辉光、仪器 |
| `temperatureProxy` | 燃料/水温的定性状态 | 负反馈、冷却表现 |
| `coolantFlowProxy` | 冷却或自然循环强度 | 水体、管路、温度 |
| `scramState` | 驱动释放与快速插入过程 | 电磁耦合、棒位、功率 |

最低运行链：

```text
操作状态
  → 每根控制棒驱动/释放
  → 棒位改变
  → 反应性代理改变
  → 功率代理改变
  → 温度代理与负反馈改变
  → 水体、切伦科夫辉光和仪器同步响应
```

所有变量都是教育性视觉代理，不能显示虚假的工程单位、临界裕量或安全结论。

## 8. 真实与近似的边界

本项目追求结构和因果关系可信，不建设核工程仿真器。

必须真实表达：

- 主要部件的存在、独立性和空间关系；
- Pavia 构型的格位、三根控制棒和主要尺寸比例；
- 控制机构、棒位、功率、冷却和可见响应之间的因果方向；
- 材料类别和水介质类型；
- 正常运动与 scram 的区别。

允许近似：

- 将厘米尺寸统一缩放到 Three.js 世界单位；
- 使用 `InstancedMesh` 表达大量同构元件；
- 使用简化网格代替不可见的制造细节；
- 使用归一化功率、温度和流量代理；
- 使用 shader、点光源和发光材质近似切伦科夫光学。

不允许：

- 混合不同设施互相冲突的格位、棒数和冷却结构；
- 把轻水反应堆称为重水反应堆；
- 把无条件循环动画称为反应堆运行；
- 把发光贴片、背景图或整面 shader 称为反应堆模型；
- 把网页代理量描述成经过验证的核工程计算结果。

## 10. 实施顺序

按以下顺序推进：

1. 把 Pavia 尺寸、格位和控制棒构型转换为统一比例尺和数据基线；
2. 为全部主要部件分配稳定 ID 和资料映射，不先做材质；
3. 重建池体、格架、燃料、控制棒和反射体几何；
4. 建立独立水体和光学边界；
5. 建立驱动、冷却、辐照和仪器连接；
6. 实现操作模式、独立棒位、功率/温度/流量代理和 scram；
7. 接入切伦科夫、水体和仪器表现；
8. 完成结构测试、状态测试、三视口与交互验收；
9. 最后调整材质、光照和性能。

不得先用视觉效果掩盖未解决的结构问题。
