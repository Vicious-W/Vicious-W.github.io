# SOURCE 实验室、光学与自由交互工程基线

DESIGN_STATUS: ACTIVE

本文件定义 SOURCE 第二阶段的实验室空间、地下设备、建筑玻璃、自由相机、轻水光学、
切伦科夫表现、双控制台和玻璃抓取规则。反应堆构型仍以
`REACTOR_POOL_SYSTEM.md` 与 `REACTOR_MODEL.md` 为准；本文件不改变 Pavia TRIGA
Mark II 的堆芯、棒数、功率或冷却拓扑。

## 1. 阶段目标

SOURCE 不再只表现一个放在空旷房间里的反应堆池。场景必须成为可自由观察的完整空间：

```text
固定玻璃砖天花板
  → 吊装、通风、照明、电缆和上部服务结构
固定玻璃砖墙
  → 反应堆大厅、控制区、仪器柜和管线穿墙
动态玻璃砖地板
  → 透明结构承托层，可搬动并显露地下设备
地下设备层
  → 换热、净化、泵阀、气动、电气、排水和管廊
反应堆池
  → 清澈轻水、可见堆芯、局部切伦科夫和连续运行
```

必须保留现有 AUTO/MANUAL 物理、脉冲、格栅、玻璃耐久、声音和会话复位。新阶段是
在原系统上增加空间、光学和交互，不是用新场景替换旧逻辑。

## 2. 事实边界与资料

  放射化学实验室和热室的地下气动传输系统。

  轻水冷却/部分慢化、90 个元件位置、三根控制棒和实验通道。
- `REACTOR_POOL_SYSTEM.md` 已锁定的三回路、两台换热器、自然循环、桥架、仪器、
  电气和气动拓扑继续有效。

公开资料不能证明 Pavia 当前所有地下设备的逐台外形和精确坐标。因此地下布局必须
标记为 `REALTIME_PROXY` 或 `TRIGA_ANALOGUE`，不得冒充 Pavia 竣工图。

### 2.2 可用于不冲突补充的正式资料

### 2.3 项目艺术决定

玻璃砖建筑、透明地板承托层、可自由穿越设备的观察相机和池口上的交互玻璃都不是
Pavia 的真实建筑事实，而是所有者锁定的 SOURCE 艺术方向。它们必须明确标记为
`SOURCE_ART_DIRECTION`，同时保持内部物理关系一致。

## 3. 实验室与地下设备

### LAB-001 建筑空间

- 重建有真实尺度层次的反应堆大厅，不使用四面简单盒子围住场景；
- 池体、作业层、控制区、设备区、楼梯、栏杆、起重/吊装空间和维护通道形成可解释
  的交通与设备关系；
- 墙、顶、地板由玻璃砖构成，但设备支架、桥架、管线和安全设施仍使用与其功能
  相符的金属、混凝土代理或工程材料；
- 建筑透明度不能让所有前后层同时糊成一团，必须使用厚度、边缘、粗糙度、色散近似
  和按距离衰减的反射来保持层次。

### LAB-002 地面设备

至少单独建模并正确连接：

- 现有 MANUAL 控制台和新增 AUTO 控制台；
- 辅助仪器柜、独立安全/停堆指示、棒驱动供电和信号柜；
- 起重机、吊钩、池边长柄工具支架、栏杆和维护平台；
- 通风风管、送/排风机组、灯具和电缆桥架；
- 池边取样、液位、温度、电导率和辐射监测设备；
- 通往地下层的管道立管、线槽、气路和可见穿板结构。

### LAB-003 地下设备层

地下设备必须是可从任意方向观察的三维系统，不是地板下的装饰贴图。最低集合：

- 一回路池水取水/回水管段与隔离阀；
- 闭式中间回路的泵、膨胀/缓冲容积和第一、第二换热器；
- 三回路冷源接口、泵阀和温度/流量仪表；
- 去离子/净化支路、过滤器、离子交换柱和取样管；
- 排水沟、集水坑、泄漏收集和受状态驱动的排水泵代理；
- TRANS 压缩空气储罐、调压/阀组和通往桥架的气路；
- 电缆管廊、接地、支架、检修空间和设备基础；
- 与 Pavia 地下气动传输事实相符的 Rabbit/样品传输管段和离场连接。

设备位置可以为网页空间重新组织，但功能拓扑不可改变。管道不能在半空结束；每台
泵、换热器、阀、储罐、过滤器和仪表都要有上游、下游、支承和状态来源。

### LAB-004 独立运作

地下和地面设备不播放无因循环。可见状态至少由以下数据驱动：

- 泵速、阀位、流向和回路温差；
- 池水温度、净化支路和水质代理；
- TRANS 气压、充气、发射、排气和复位；
- AUTO/MANUAL 所有权、联锁和 SCRAM；
- 通风和辅助电源状态。

## 4. 玻璃砖建筑

### GLA-001 固定建筑玻璃

- 墙壁和天花板由可辨认的独立玻璃砖单元组成；
- 单元具有真实厚度、砖缝、内外表面、折射和静态碰撞；
- 它们属于固定建筑结构，不可抓取、不进入自由刚体求解，也不会因场景启动自行移动；
- 可以使用实例化和合批降低渲染成本，但不能退化成一张玻璃砖贴图；
- 本阶段不要求墙顶玻璃具有和动态玻璃相同的破碎系统。

### GLA-002 动态地板玻璃

- 地板由独立、可抓取的玻璃砖刚体铺成；
- 地板砖放在一层连续、透明、无装饰纹理的结构碰撞层上；
- 该支承层是所有者明确要求的 `SOURCE_ART_DIRECTION`，只承托地板砖，不冒充
  反应堆池安全格栅；
- 移开地板砖后应能透过缺口清楚看到地下设备，观察相机不受该碰撞层阻挡；
- 地板砖与格栅玻璃共用质量、摩擦、耐久、裂纹、破碎、音频和会话复位系统；
- 地板初始布局确定，刷新后恢复位置、朝向、耐久和碎片状态。

### GLA-003 性能边界

- 固定墙顶优先实例化、空间分区和静态碰撞合并；
- 动态地板只对活动/近相机砖保持高频求解，其余允许休眠；
- 不能为了性能把所有动态地板变成一个不可移动平面；
- 不能让透明排序错误导致墙顶完全遮住反应堆和地下设备。

## 5. 自由观察相机

### CAM-001 两种观察方式

相机提供可连续切换的统一自由观察：

- 轨道观察：右键拖动旋转，中键拖动平移，滚轮连续靠近/远离；
- 自由飞行：没有抓取玻璃时，`W/S` 前后、`A/D` 左右、`Q/E` 上下，鼠标改变朝向；
- `Shift` 只作为速度倍率，不改变物理时间；
- 不增加文字帮助层，控制状态可通过光标、微弱准星或纯图形反馈表达。

### CAM-002 空间自由

- 移除当前围绕池口的硬性方位、距离和高度限制；
- 相机可以越过地板、进入地下设备层、穿过水面并接近堆芯；
- 观察相机不参与刚体碰撞，不会推动玻璃、设备或水体；
- 近裁剪面和深度精度必须允许贴近小型部件，同时避免严重 z-fighting；
- 穿入封闭实体时不重置会话；必要时提供非文字的快速回到初始取景动作。

### CAM-003 水面跨越

相机位置相对名义水面是水上/水下光学的唯一判据：

- 水上：看到水面反射、透射、波纹、堆芯折射和辉光经水面后的表现；
- 水下：启用体积衰减、散射、焦散、颜色变化和不同的远景雾化；
- 跨越水面不新建水体、反应堆或玻璃会话；
- 摄像机进入地下也不能暂停 AUTO/MANUAL 物理。

## 6. 动态玻璃抓取

### GLA-CTRL-001 抓取位置

- 只有格栅玻璃和动态地板玻璃可被左键抓取；
- 左键按住期间，鼠标只改变世界水平面上的目标位置；
- `W/S` 改变世界竖直轴上的目标高度；
- 抓取目标通过有界约束/伺服力跟随，不能每帧直接传送穿过碰撞体；
- 抓取期间玻璃仍参与碰撞，但约束力、速度和穿透修正必须有上限。

### GLA-CTRL-002 抓取朝向

- 抓取成功时清除已有随机角速度；
- 鼠标移动和 `W/S` 不改变朝向；
- `A/D` 只绕世界竖直轴进行左/右偏航；
- 抓取时锁定初始俯仰与翻滚，不允许上下翻转或侧滚；
- 松开时保留最终位置和朝向，但不注入随机角速度；
- 松开后重新交给刚体系统，后续真实碰撞仍可使其旋转。

### GLA-CTRL-003 输入所有权

- 抓取玻璃时，`W/S/A/D` 专用于玻璃，不能同时移动相机；
- 松开后这些键恢复自由飞行控制；
- 键盘丢焦、指针取消、窗口失焦或对象破碎时必须安全释放约束；
- 抓取不改变 AUTO/MANUAL 控制权，除非它本身是首次控制台外有效交互。

## 7. 轻水光学重构

### WTR-001 清晰度与可见性

- 轻水必须清澈到能从池口识别堆芯、控制棒、反射体和池底结构；
- 不用单一高不透明蓝色表面遮住内部；
- 吸收和散射随实际光程增加，近处清晰、远处逐渐衰减；
- 水本身与切伦科夫分开：反应堆停堆时水仍然可见，但不会自发发出强蓝光；
- 池壁、金属部件和玻璃使用同一相机/水体关系计算水下表现。

### WTR-002 水面与体积

- 水面保留高度场的波动、反射和阻尼；
- 体积层负责深度吸收、水下散射、热羽流折射和远景雾化；
- 水面法线来自实际波场，不使用与动力学无关的滚动噪声代替；
- 焦散强度随水面法线、照明和被照物深度变化；
- 水上、水下和穿越水面时没有明显的双重表面、排序翻转或整体消失。

### WTR-003 动力学保持

光学重构不能破坏现有物理：

- TRANS、水下部件和入水碎片仍驱动波场；
- 浮力、阻力、温度和自然循环仍由原状态计算；
- 视觉参数只能读取这些状态，不能反向偷偷改写功率或玻璃速度。

## 8. 切伦科夫体积与粒子表现

### CHR-001 物理驱动

- Pavia 稳态辉光按官方资料在约 100 kW 以上逐渐可见，不使用任意低功率常亮底色；
- 脉冲辉光读取独立的毫秒功率通道，不把瞬态峰值作为持续热输入；
- 发光区域附着于实际堆芯/燃料体积，不附着水面或相机；
- 强度、范围、颜色和衰减是功率、功率分布、水体光程和曝光状态的函数。

### CHR-002 表现层

辉光至少由相互一致的四层组成：

1. 堆芯附近的局部发光几何/材质；
2. 水中的体积散射与沿深度衰减；
3. GPU 粒子或点精灵形成的光子传播视觉代理；
4. 受控 bloom/曝光恢复，让高功率与脉冲可见但不过曝整屏。

粒子不是电子、中子或可碰撞物质的逐粒子模拟，也不是蓝色尘埃。它们必须标记为
`TUNED_PRESENTATION`：

- 从堆芯发光体积采样起点；
- 发射率由功率状态确定，随机数只用于稳定采样分布并使用固定种子；
- 速度、寿命、颜色和透明度表达水中光传播/散射的视觉近似；
- 不产生碰撞、浮力、损伤或声音；
- 相机和水面通过统一深度/折射关系观察它们；
- 降级时先减少粒子密度，不取消局部体积辉光和功率因果。

### CHR-003 可见性与安全

- 250 kW 平衡时，从默认水上取景必须明确看到堆芯周围蓝色辉光；
- 水下靠近堆芯时应看到更强的局部层次，而不是全池均匀蓝；
- 历史脉冲具有短促高亮和有界曝光恢复，不延长核动力学时间；
- `prefers-reduced-motion: reduce` 下禁止危险强闪，使用较低峰值和更平滑恢复；
- 辉光移除后水仍透明可见，水移除后辉光不能悬在空气里被误认为灯具。

## 9. MANUAL 与 AUTO 双控制台

### CTL-001 MANUAL

- 保留现有三维人工控制台和全部命令；
- 允许改进几何、材质、联锁反馈和可达性，但不得删除已有能力；
- 人工指令继续通过同一个 session controller 原位接管。

### CTL-002 AUTO

- 在 MANUAL 控制台旁建立物理独立的 AUTO 控制台；
- AUTO 面板具有独立几何、按钮、阶段灯、棒位/功率/冷却/联锁反馈；
- 页面无文字，因此使用布局、形状、运动、颜色和非文字刻度表达状态；
- AUTO 面板只调用现有自动程序和共享命令，不建立第二套反应堆状态；
- AUTO 与 MANUAL 面板不能同时拥有设备控制权；
- 安全停堆后的 AUTO 重入只从 AUTO 面板的明确控件发起。

### CTL-003 来源边界

General Atomics 资料支持 MANUAL/AUTO 和独立仪控子系统，但 SOURCE 的无文字双实体
控制台布局属于项目决定，不宣称复制 Pavia 当前控制室。

## 10. 建模精细化

“进一步精细化”必须表现为结构信息，而不是增加随机小物件：

- 主要设备增加壳体厚度、法兰、螺栓、支架、底座、检修盖和真实连接端；
- 管道增加弯头、三通、阀、泵、仪表、支承和穿墙/穿板关系；
- 电缆、刚性导管、柔性软管和气路使用不同截面、材料与弯曲约束；
- 地下设备和池内设备共享状态，不允许两个同名泵或换热器各自动画；
- 可移动/可运作部件拥有独立对象和状态；完全固定的重复件可实例化；
- 未有 Pavia 精确资料的尺寸和布置登记差距，不用“先进实验室”四字伪造真实性。

## 11. 性能与降级

目标是桌面和移动视口都可用，而不是只在开发机截图：

- 固定玻璃砖、螺栓和重复管夹使用实例化；
- 地下不可见区域按房间/层级做视锥裁剪和可见性分组；
- 透明对象严格分层，避免所有砖、水和粒子同时全屏过度绘制；
- 粒子、焦散和体积采样提供质量档，但几何、设备连接和控制状态不能被降级掉；
- 动态地板砖使用休眠、近场唤醒和碎片上限；
- 记录 390×844、768×1024、1440×900 的帧率、绘制调用、三角形、活动刚体和粒子数。

## 12. 验收矩阵

### 空间

- `LAB-001`：默认取景能辨认完整大厅，而非空盒子；
- `LAB-002`：地面设备有真实连接和状态；
- `LAB-003`：自由相机可进入地下并沿管线确认三回路、净化、气动、电气和排水拓扑；
- `LAB-004`：设备只因对应状态运作。

### 相机

- `CAM-001`：轨道、平移、连续缩放和自由飞行均可用；
- `CAM-002`：可到达水下、堆芯附近、地板以下和地下设备背面；
- `CAM-003`：跨水面/地面不复位会话、不夺取控制权、不触发音频风暴；
- 三种目标视口中均无硬性死角，且可回到规范初始取景。

### 水与辉光

- `WTR-001`：停堆和满功率时均能透过轻水识别堆芯；
- `WTR-002`：水上、水下和水面穿越的反射/折射/衰减连续；
- `WTR-003`：现有水动力、浮力和脉冲耦合测试继续通过；
- `CHR-001`：辉光强度和位置可追溯到功率与堆芯；
- `CHR-002`：体积、粒子、折射和 bloom 是一个系统，不是四段无关动画；
- `CHR-003`：250 kW 默认取景明显可见，脉冲短促可见，低功率不常亮。

### 玻璃
