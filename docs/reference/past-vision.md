## 1. 贯穿始终的核心构想

- **V-01**【原话】整体颜色以蓝色为主，蓝色是全站的核心颜色。〔2026-06-23 起，此后每一版都保留〕
- **V-02**【原话】自然物体保留真实的颜色、光照和材质：天空、云、地表、火焰、飞行器
  不强行染蓝。〔2026-07-31〕
- **V-03**【归纳】画面里的蓝几乎都来自本身就是蓝色的真实现象——天空、水、切伦科夫
  辉光、玻璃——而不是把物体涂成蓝色。
- **V-04**【原话】要有强烈的表现力、视觉冲击力和有趣的交互；"在静态网站这个前提下，
  尽量把效果做得惊艳"。〔2026-06-23〕
- **V-05**【原话】整体气质：简约、高级、交互有趣；展现个性与艺术追求；具有几何、数学、
  自然美感。〔2026-06-23〕
- **V-06**【原话】主要内容是可交互的真实三维物理场景，而不是装饰性的背景。〔2026-07-23 起〕
- **V-07**【原话】主要物体必须有真实的三维几何：不用照片、背景图、预渲染画面代替；
  不在"一整块画面上划分"出假物体；shader 只负责材质、光学、水和辉光；纹理只做表面
  细节。〔2026-07-22 / 07-23〕
- **V-08**【原话】运动、声音和粒子由可解释的状态或物理事件驱动，不用与状态无关的
  装饰性循环动画。〔2026-07-23 起〕
- **V-09**【原话】声音在用户第一次手势后才启用；碰撞、滑动、机构、风等声音都来自对应
  的物理事件。〔2026-07-22 起〕
- **V-10**【原话】真实感优先于实现速度，允许分阶段重建。〔2026-06-23〕
- **V-11**【原话】页面没有可见文字：没有个人介绍、标题、导航、链接、联系方式或内容区。
  〔2026-07-23〕后来 FLY 允许两类例外：飞行器操作指南；真实设备自带的标签、刻度、

- **V-13**【原话】入口是无文字的三维场景选择：用实时三维缩影、运动、光色和声音区分

- **V-14**【规格】场景之间相互独立：切换时彻底释放上一个场景，同一时刻只运行一个；

## 2. 你对"不满意"的判断（从历次反馈提炼）

这一节最能说明你要的是什么，也是重建时最需要避开的坑。

- **L-01**【原话】水塘"很丑、不自然"。〔2026-06-23〕
- **L-02**【原话】水塘"完全未达到预期"：程序化叶片、规则浮叶和循环游动的鱼产生了
  明显的图案感、屏保感。〔2026-07-17〕
- **L-03**【原话】水塘"像天空贴图覆盖生态底图"：缺少水的表面感和纵深，水草基本
  看不见，云影过于清晰、明亮和均匀。〔2026-07-19〕
- **L-04**【原话】玻璃砖"非常假"；第二轮"还是不够真"，而且"每块砖看起来完全一样"。
  〔2026-07-22〕
- **L-05**【原话】"你是在一整块玻璃上『划分』出一块块玻璃"——画面里根本不存在一个个
  真实的物体，方向从根上就错了。〔2026-07-22〕
- **L-06**【原话】"仍然看不出每个玻璃方块都是正方体"；"就像一个个玻璃正方体放在深色
  的槽里"——缺少透视、侧面和真实的光学关系。〔2026-07-22〕
- **L-07**【原话】反应堆"像动画片，不像真的反应堆"，蓝色辉光"很假"；要求先查真实
  核反应堆的图片和视频再做。〔2026-07-22〕
- **L-08**【原话】玻璃立方体"手感偏飘"、材质不够真实、没有物理声音。〔2026-07-22〕
- **L-09**【原话】取消鼠标视差效果。〔2026-07-22〕
- **L-10**【原话】FLY"整体仍显原始"：控件难以发现和点击，驾驶员视角别扭，晴空和风景
  不够可信。〔2026-08-07〕
- **L-11**【原话】"以前的实现我都不满意"。〔2026-11-04〕
- **L-12**【归纳】反复出现的根因有两个：
  1. **看起来假**——结构、材质、光、运动、声音中只要有一处不真，整体就会出戏；
  2. **范围不断扩大**——反应堆实验室又加了地下设备层和双控制台，FLY 一开始就规划了
     6 类飞行器和 4 类天气，规格文档累计数千行，结果每个部分都很难打磨到你满意的
     完成度。

## 3. 场景构想

### 3.1 雨后小水塘（2026-06 → 07，曾是四屏主页的第四屏）

- **P-01**【原话】夏天下完雷阵雨后的小水塘：天空蓝而透彻，积雨云有体积感，水面倒映
  蓝天白云；透过水面能隐约看到随水摆动的水草，偶尔有小鱼游过；鼠标划过水面会产生
  涟漪；"一切都应有物理性质和真实质感"。〔2026-06-23〕
- **P-02**【规格】第一眼就能认出是雨后小水塘，而不是抽象的蓝色纹理。〔2026-06-23〕
- **P-03**【原话】参考图的核心是明亮、清澈、俯视的浅水生态：密集鲜绿的植物、浮萍、
  大浮叶、羽状水草、小鱼和局部水面高光。〔2026-06-23〕
- **P-04**【原话】后来的方向：大部分植物退到水面以下，显著扩大蓝天白云倒影的占比；
  云要动态漂移；涟漪同时扭曲倒影并惊动水下的鱼；"整体遵循物理直觉"。〔2026-07-19〕
- **P-05** 状态：7/23 改为单页单场景时被移除，此后没有再做。

### 3.2 SOURCE：玻璃 × 蓝色水池 × 核反应堆（2026-07）

- **S-01**【原话】画面构想：三层结构——底层核反应堆、中层水、表层无色透明的玻璃砖；
  透过玻璃俯视池底，全画面被切伦科夫蓝色辉光浸透；每一层都有各自的物理特征。
  〔2026-07-20〕
- **S-02**【原话】玻璃是"互相靠在一起的、独立的玻璃正方体"：能看出每块都是正方体，
  有透视和侧面；每块的物理特征随机、各不相同；直接互相贴合，不要深色槽壁。
  〔2026-07-22〕
- **S-03**【原话】玻璃立方体可以用鼠标抓起，拖到任意位置，叠在其他立方体上；手感
  有重量、稳定；碰撞和滑动发出相应的玻璃声音；材质像有厚度的透明玻璃，不像蓝色
  塑料。〔2026-07-22〕
- **S-04**【规格】玻璃会因碰撞能量累积损伤、出现裂纹；真正破碎时，碎片是独立的
  三维物体；刷新后复原。〔2026-07-23〕
- **S-05**【原话】反应堆依据真实研究堆的公开资料建模，主要部件各自独立，并有真实的
  运行关系。原型选定为意大利帕维亚大学的 Pavia TRIGA Mark II；池内是轻水（最初构想
  写的是"重水"，确定原型后按资料改为轻水）。〔2026-07-22 / 07-23〕
- **S-06**【原话】实心玻璃放在池口上方放下并锁定的安全格栅上，而不是漂在水面上。
  〔2026-07-23〕
- **S-07**【原话】运行方式：页面打开时反应堆处于停堆复位状态。第一次交互后，反应堆
  可以自动完整运行（包含一次历史脉冲，最终在 250 kW 达到平衡），也可以在三维控制台
  上手动操作。两种方式共用同一套物理，可以随时手动接管。脉冲不能表现成核爆。
  〔2026-07-23 / 07-24〕
- **S-08**【原话】空间扩展：
  - 按资料重建反应堆大厅；墙、地板、天花板由玻璃砖构成；
  - 地板砖可以搬动，移开后能看到地下设备层；
  - 水必须清澈，从水面上方能看见池内的堆芯；
  - 切伦科夫蓝光是视觉重点：位于堆芯附近，随功率变化，并加入粒子表现；
  - 手动控制台旁边再加一个自动控制台。
  〔2026-07-28〕
- **S-09**【原话】操作手感：
  - 抓取玻璃时，鼠标控制水平位置，`W/S` 控制上下，`A/D` 只控制偏航，不随机旋转；
  - 相机按住右键、以画面中心为焦点慢速旋转，滚轮平滑推进，方向键平移，`Home/F`
    复位；
  - 相机可以进入水下、堆芯附近和地下。
  〔2026-07-28 / 07-30〕
- **S-10** 状态：2026-07-31 你验收了当时的 SOURCE；现在你表示以前的实现都不满意。

### 3.3 FLY：天空与飞行（2026-07-31 → 08）

- **F-01**【原话】FLY 是以真实大气、气象和飞行器为核心的无限天空旅程。〔2026-07-31〕
- **F-02**【原话】体验流程：进入 FLY → 无文字地选择气象和飞行器 → 显示该型号的操作
  指南 → 用户主动出发，以驾驶员身份手动驾驶 → 旅程中可以请求符合该飞行器真实能力的
  自动结束（飞机返航着陆，热气球寻找安全地点降落回收，航天飞机进近滑翔着陆）。
  〔2026-07-31〕
- **F-03**【原话】旅程在程序化生成的天空、地面/海洋、云层和天气中连续进行。〔2026-07-31〕
- **F-04**【原话】统一物理：一个时钟、一个世界；大气、风、飞行器、声音和视觉共用同一个
  状态；视觉和声音读取物理结果，不用动画冒充动力学。〔2026-07-31〕
- **F-05**【原话】远期范围：
  - 飞行器：热气球、固定翼、喷气式、旋翼、航天飞机、UFO（UFO 明确为虚构，但内部
    规则自洽）；
  - 天气：晴空、多云、雷暴、台风；
  - 不同类别使用各自真实的飞行模型，不能换皮复用。
  〔2026-07-31〕
- **F-06**【原话】第一阶段：晴空 + Cameron C-100 热气球。手动控制燃烧器和顶部放气；
  方向只能靠不同高度的风，没有虚构的水平推力；自动安全降落不能瞬移。〔2026-07-31〕
- **F-07**【原话】8/07 试玩反馈：基础流程已经有了，但"整体仍显原始"。要求：
  - 控制方便、容易发现，操作指南与画面上的控件一一对应；
  - 驾驶员视角稳定，有地平线，能看到篮筐和燃烧器，不穿模，不迷失方向；
  - 每个看起来可以操作的图形都有清楚的反馈，而且真的能点；
  - 风景和天气与飞行器同样是核心：晴空的大气、云、光照、能见度、风、地貌、水体、
    植被和尺度感都要可信。
  〔2026-08-07〕
- **F-08**【归纳】参考图里的"高空俯瞰云海"和"深蓝天空下的积云"与 FLY 的天空构想
  一脉相承。
