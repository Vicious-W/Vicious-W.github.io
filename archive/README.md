# 历史归档

本目录中的内容已经退出当前网站运行链路，但为了理解项目演变和必要时恢复旧思路而
保留。Vite 入口和当前源码不应引用这里的文件。

## 目录

- `legacy-site/`：2025 年第一版个人网页遗留的脚本、图标、人物图和音乐。
- `site-snapshots/2026-06-23/`：四屏版本向蓝色版本过渡时保存的页面截图。
- `unused-production-assets/`：曾用于实验或旧版本、当前没有源码引用的天空和纹理。

“归档”表示不再运行，不表示可以随意删除。若要重新启用某项内容，应先把它迁回
当前 `src/` 架构、重新验证，再从业务源码引用。
